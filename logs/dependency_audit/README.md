# Archived matroid dependency audit

These files record the stages that preceded the canonical mathematical specification in [`Matroid/LEDGER.md`](../../Matroid/LEDGER.md): blind manuscript extraction, normalization, and an independent comparison with the older manuscript-wide raw dependency graph.

The archived files are historical evidence, not active working ledgers. Their contents were preserved when moved here; internal relative links reflect their original locations. The normalized ledger supplied stable `N###` identifiers, and the comparison identified the local adjudications incorporated into the canonical ledger.

- `blind/`: initial blind extraction and its report.
- `normalization/`: frozen normalized ledger and freeze marker.
- `comparison/`: normalized-versus-raw report and row-level crosswalk.
- `raw_graph/`: independent raw node and edge tables.
